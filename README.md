# GT2-pulley-and-belt-generator

This standalone web page allows to generate dxf files for GT2 pulleys and GT2 belts.
The belt can be either bent around a pulley, an idler or left straight.

You can use this generator right here on github:

https://loaded-dice.github.io/GT2-pulley-and-belt-generator/
